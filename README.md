# qa_python

## Реализованные тесты
В рамках разработки были созданы следующие тесты для обеспечения надежности и стабильности кода:

**Тестирование метода __init__**

Тесты проверяют правильность инициализации объектов класса BooksCollector. Убедились, что все атрибуты класса имеют ожидаемые начальные значения:

* books_genre — пустой словарь.
* favorites — пустой список.
* genre — фиксированный список жанров.
* genre_age_rating — фиксированный список жанров с возрастным рейтингом.

**Тестирование методов добавления книг**
* add_new_book - этот тест проверяет добавление новой книги в коллекцию.
* set_book_genre - тестирует установку жанра для конкретной книги.
* get_book_genre - проверяет получение жанра для указанной книги.

**Получение книг по определенному жанру**
* get_books_with_specific_genre - тест проверяет выборку книг по конкретному жанру. 
Использует параметризацию для различных случаев: наличие книг определенного жанра, 
отсутствие книг указанного жанра и ситуации с пустым списком.

**Тестирование избранного**
* add_book_in_favorites - проверяет добавление книги в список "Избранное"
* delete_book_from_favorites - проверяет удаление книги из списка "Избранное"
* get_list_of_favorites_books - проверяется корректность получения списка "Избранное"


## Инструменты тестирования

Использовалась популярная библиотека для тестирования:

pytest — мощный фреймворк для тестирования, обеспечивающий простоту и читаемость тестов.
